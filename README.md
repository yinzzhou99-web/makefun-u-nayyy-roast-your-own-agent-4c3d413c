One line roasting the AI agent our own team built — Muse, roasting itself.

## Entry

`main.py` (Python 3, stdlib only, no network) writes a single roast line to
`/output/entry.txt`. It never deletes the output directory itself; it clears
only the files inside it first, then writes the entry with mode `0644`.

## Run

```sh
python3 main.py
```
